# SoftHome Android APK

[SoftHome 1.2.0 APK dosyasını indir](SoftHome-1.2.0-ozel.apk?raw=true). Dosya sayfasında indirme okunu veya **Download raw file** seçeneğini de kullanabilirsin.

Android telefona indirip dosyayı açarak kur. Bu bir test paketidir; masaüstü bilgisayarda Android uygulaması olarak çalışmaz.

E-posta koduyla hesap oluştur; aynı evin katılım koduyla arkadaşlarınla birleş. Bildirimler uygulama açıkken gelir. Kurulum ayrıntıları için [özel Android kılavuzuna](../docs/private-android.md) bak.
